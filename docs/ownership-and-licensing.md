# Ownership and licensing

No public open-source licence has been selected for this repository. A licence and release model must be chosen before the project is distributed publicly.

Contributors should create original implementation code and must not copy proprietary source, reverse-engineered source, or licence-incompatible material from commercial Power BI tools. Product behaviour and publicly documented file formats may inform requirements, but competing implementations must not be treated as source material.

Before wider contribution or distribution, the project should establish:

- Who owns contributed code and documentation.
- Whether the repository will remain private or become open source.
- The approved licence if it is published.
- Required contributor and copyright notices.
- A reviewed inventory of third-party packages, tools, and licences.
